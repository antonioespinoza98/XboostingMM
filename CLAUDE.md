## Project

**XboostingMM** is an R package implementing a semi-parametric model for Small Area Estimation (SAE) that combines XGBoost with mixed-effects models for hierarchical data. The core algorithm is an iterative EM-like procedure alternating between tree boosting and random-effects updates.

## Commands


## Architecture

The algorithm in two phases:

1. **`xboosting()`** (`R/xboosting.R`) — Fits XGBoost trees with a custom initialization (starts from the mean of `y` rather than 0). Returns an `xtremeBoost` S3 object containing the list of models, per-tree predictions, and final fitted values.

2. **`boost_mem()`** (`R/boost_mem.R`) — Main entry point. Runs the iterative loop:
   - Transforms the outcome: `Ystar = Y - Z*b_hat` (subtracts estimated random effects)
   - Calls `xboosting()` on `Ystar`
   - Updates random effects and variance components (`D_hat`, `Sigma2_hat`)
   - Checks convergence via GLL (`R/convergence.R`)
   - Returns an `XtremeRMM` object with the boosting ensemble, variance estimates, random effects, and convergence diagnostics.

Supporting functions:
- `predict.xgb()` (`R/predictxgb.R`) — S3 prediction method for `xtremeBoost` objects
- `validation()` (`R/validation.R`) — Compares model estimates against direct survey estimates using `survey`/`srvyr`, produces a `ggplot2` plot with confidence intervals
- `mem_boost_gll()` (`R/convergence.R`) — Computes Generalized Log-Likelihood for convergence checking
- `R/globals.R` — Declares global variables (`max_inter`, `min_inter`, `pred`) to suppress `R CMD CHECK` notes

## Key Details

- Uses `Matrix::sparse.model.matrix()` for feature encoding (sparse matrices throughout)
- Formula-based API: `boost_mem(y ~ x1 + x2, group = "area", data = df, ...)`
- `NAMESPACE` and `/man/*.Rd` files are auto-generated by roxygen2 — edit only the `@` tags in source files, then run `devtools::document()`
- Tests in `tests/testthat/` cover both `xboosting()` and `boost_mem()` and verify class types, output structure, and convergence

## Core Reference

The methodology follows **Salditt et al. (2023)** "Gradient Tree Boosting for Hierarchical Data" — understanding that paper is the fastest path to understanding the algorithm's math.
